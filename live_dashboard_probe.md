# Live Dashboard Probe

## Code-live-Feld

Das Code-live-Feld ist ein interaktives Element des Live-Dashboards, das es Nutzern ermöglicht, Code-Eingaben direkt im Browser zu tätigen und diese in Echtzeit ausführen zu lassen. Es bietet eine sofortige Rückmeldung zu Code-Änderungen und ermöglicht so ein dynamisches Programmiererlebnis ohne Neuladen der Seite.
