# Flask-Dashboard

## Starten:
1. Öffne ein Terminalfenster.
2. Verwende `python3` um den Flask-Server zu starten: `python3 /root/local_agent/agent_workspace/flask_app.py`
3. Der Server läuft auf Port 11437.
