# Neues Hilfswerkzeug
Dieses Dokument enthält grundlegende Anweisungen zum Erstellen eines neuen Hilfswerkzeugs in diesem Workspace.
### Schritt 1: Ein neues Hilfswerkzeug erstellen
- Skript erstellen und speichern mit dem Namen 'new_tool.py'.
- In 'new_tool.py' fügen Sie die grundlegenden Anweisungen für das neue Werkzeug ein.
### Schritt 2: Testversion erstellen
- Fügen Sie Tests hinzu, um sicherzustellen, dass das Werkzeug korrekt funktioniert.
- Documentation der Testergebnisse in 'new_tool.md' speichern.
