# Port 8085 Test Script

## Beschreibung:
Dieser Skript bewertet, ob der Port 8085 auf localhost offen ist. Der Skript verwendet `nc` (Netcat) für die Überprüfung.

## Befehl zum Ausführen:
1. Skript lokal starten: `/root/local_agent/agent_workspace_support/test_port_8085.sh`
2. Die Ausgabe beobachten, um zu sehen, ob der Port offen ist oder geschlossen ist.
