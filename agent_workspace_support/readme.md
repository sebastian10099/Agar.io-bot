# README

Dieses Repository enthält verschiedene Werkzeuge und Dienstprogramme. Um den Flask-Server auf Port 8085 zu starten, führen Sie die folgenden Befehle aus:

1. Stellen Sie sicher, dass Python installiert ist.
2. Starten Sie den Flask-Server mit: `python /root/local_agent/agent_workspace_support/flask_app.py`.
