#!/usr/bin/env bash

## Beschreibung des Scripts
Dieses Script lädt Flask-Dashboards auf Port 8085.

### Starten der Dashboards:
1. Öffne ein Terminalfenster.
2. Stelle sicher, dass die Datei `start_flask_dashboards.sh` im gleichen Verzeichnis wie das aktuelle Terminal ist.
3. Führe den folgenden Befehl aus: `/root/local_agent/agent_workspace_hermes/start_flask_dashboards.sh`

### Beispiel für die Anzeige der Daten:
Um die JSON-Werte anzuzeigen, erstelle eine einfache Flask-App oder HTML-Seite, die diese Werte liest. Dies kann in einem separaten Script erfolgen.
